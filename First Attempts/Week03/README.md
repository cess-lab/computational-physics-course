# PHY4605 Week 03

Week 3 develops linear-system modelling through Kirchhoff circuits. The emphasis is deriving equations before assembling a matrix, preserving units and sign conventions, solving with MATLAB's backslash operator, and validating the result using rank, conditioning, residuals, current balance, and power balance.

## Materials

- `Lecture_Slides_Week03.pptx` — lecture slide deck.
- `Week03_Linear_Systems_Through_Kirchhoff_Circuits.pdf` — learning note.
- `Week03_Lecture_Demonstration_Linear_Systems_Through_Nodal_Analysis.m` — complete instructor-led two-node circuit demonstration.
- `Week03_Practical_Solve_and_Validate_a_Two_Loop_Circuit.m` — group practical using Kirchhoff's voltage law and mesh currents.

The lecture demonstration may be downloaded before class and kept as a worked example. At the start of the practical, each student must complete the `Week 03 Individual Practical Check — Quiz` in Google Classroom before discussing the problem or using MATLAB, notes, calculators, or AI. The Week 03 quiz is created and published only after its diagnostic questions are approved.

MATLAB Copilot is allowed during the group practical. Record any material AI use and validate suggestions using equation derivation, units, sign conventions, rank, conditioning, residuals, Kirchhoff balances, and power conservation. The `.m` files use MATLAB's plain-text Live Script format and require MATLAB R2025a or later.

This week also introduces bounded capstone problem spaces. Groups are not required to select a final question yet; keep a short record of candidate physical systems, possible computational methods, measurable outputs, and plausible validation evidence.
