# PHY4605 Week 04

Week 4 develops eigenproblem reasoning through coupled oscillators. The emphasis is deriving the generalized eigenproblem from Newton's law, interpreting eigenvalues as squared angular frequencies and eigenvectors as collective mode shapes, and validating the computed modes using symmetry, analytic reference values, eigen-equation residuals, mass orthogonality, and limiting cases.
