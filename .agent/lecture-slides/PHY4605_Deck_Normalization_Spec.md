# PHY4605 Lecture Deck Normalization Specification

Approved implementation for the 2026/2027 Semester 1 courseware revision.

## Topic-title rule

Use one scientific or mathematical term, followed by a colon, followed by a sentence that states the week's computational purpose. The approved Week 01–14 titles are maintained in the course blueprint and the root README. Use the exact approved wording in the visible learning note, Live Script heading, practical material, deck outline, speaker notes, deck metadata, and title slide.

## Title-slide template

- 16:9 complete raster image using the Codex-PPT Teaching Courseware style.
- Overline: `PHY4605 · WEEK NN · LECTURE`; use `CAPSTONE` for Week 13 and `BUFFER` for the Week 14 guide only.
- Main title: the exact approved topic title, with the scientific term and colon sentence as one hierarchy.
- Thin deep-navy horizontal rule beneath the title.
- Small course chain: `Model → Units → Algorithm → Code → Validation → Interpretation`.
- One restrained week-specific scientific anchor; no syllabus list, logo, slide number, or outer frame.
- Warm-white/pale paper canvas; navy structure; dusty blue model content; sage validation; restrained ochre prompt; coral only for a genuine defect.

## Last-slide template

- 16:9 complete raster image using the same Teaching Courseware identity.
- Overline: `WEEK NN · TAKEAWAY AND NEXT STEP`; use `CAPSTONE HANDOFF` for Week 13.
- Headline: the approved topic term plus a short closing sentence.
- Three equal cards: `CORE IDEA`, `CHECK`, and `NEXT STEP`.
- Bottom exit-ticket strip: `What changed?` and `How do you know?`.
- Week 13 uses `EVIDENCE`, `DEFENCE`, and `HANDOFF` cards. Week 14 has no planned new deck.
- Never use a generic “Thank You” ending, a slide number, a thick frame, or a decorative footer.

## Scope

Only the first and last slide images are remade in this normalization pass. Interior scientific content, equations, MATLAB code, units, numerical values, strict plots, and speaker-note evidence remain unchanged except where the approved title metadata is updated.
