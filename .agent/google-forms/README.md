# PHY4605 Weekly Practical Quiz Forms — Agent Configuration

Google Classroom is the student-facing system of record for PHY4605 pre-practical diagnostics. Each approved practical week uses one dedicated Google Form quiz attached to one corresponding Classroom assignment. The former course-wide Week 01-14 routing Form has been retired and deleted.

The canonical live mapping is `PHY4605_Classroom_Practical_Quiz_Forms.json`. Read that file before creating or editing any weekly practical diagnostic so existing Forms and Classroom coursework are reused rather than duplicated.

## Update workflow

1. Read `PHY4605_Classroom_Practical_Quiz_Forms.json` and confirm whether the week already has a Form and Classroom coursework item.
2. Create a new weekly Form only after that week's lecture/practical material and diagnostic questions are approved.
3. Configure the Form as a quiz, collect verified institutional email, and add the approved questions and answer keys.
4. Attach the Form to the corresponding Google Classroom coursework using the Form's Drive/editor URL so Classroom upgrades the attachment to native `form` material.
5. Keep the Classroom coursework ungraded unless the lecturer explicitly changes the design.
6. Publish only after verifying question count, required flags, quiz settings, Form attachment type, and wording.
7. Record the Form ID, responder URL, Classroom coursework ID, and Classroom URL in the canonical JSON mapping.

## Weekly diagnostic pattern

Use approximately six required questions that can be completed independently before group work:

- one physical prediction;
- one units or scaling question;
- one algorithm, array, pseudocode, or code-tracing question;
- one method or numerical-behaviour question;
- one short validation-reasoning response; and
- one confidence item using the same 1–5 labels every week.

Prefer four automatically countable conceptual items and one short response. The diagnostic remains ungraded in Classroom unless the lecturer explicitly changes the design. Use one Classroom assignment backed by one weekly Form; do not create six separate Classroom stream items.

Do not add redundant `Full name`, `Matric number`, or `Select practical week` questions. Classroom provides coursework context and the weekly Form collects verified institutional email.

## Privacy and analysis

Remove identifying information before sending response text to a general-purpose AI system unless an approved institutional workflow explicitly requires identification. Report cohort patterns, confidence calibration, and recurring misconceptions rather than ranking students.

See each `WeekXX_Question_Key_and_AI_Analysis.md` file for that week's answer key, misconception tags, and analysis prompt.
