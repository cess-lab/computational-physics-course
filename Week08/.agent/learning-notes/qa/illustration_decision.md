# Embedded illustration decision

No ImageGen illustration was used. The main representation barrier in this note is how the discrete Euler states diverge from the continuous reference as the timestep changes. The retained MATLAB figure directly displays that numerical relationship, including the exact trajectory, discrete update points, timestep values, and ambient-temperature bound. A visual-only illustration would not communicate the required numerical evidence as clearly and would duplicate the figure's instructional role.

The MATLAB figure is a strict reference asset generated from `../assets/make_week08_reference_plots.m` in a fresh MATLAB session. It is embedded with a deterministic caption and accessibility description in the compiled PDF.
