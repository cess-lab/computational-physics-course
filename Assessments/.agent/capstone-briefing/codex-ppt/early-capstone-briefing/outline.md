## Core contract

- Ten groups receive ten distinct, lecturer-assigned problem briefs.
- No starter Live Script is required and no common solution path is prescribed.
- Each brief gives a physical scenario, available initial information/data, and a broad real-world objective.
- Students decide model scope, added physics, assumptions, numerical method, code structure, evidence strategy, and analysis.
- Highest marks reward the most physically faithful, relevant, defensible approximation—not complexity for its own sake.
- Capstone remains provisionally 15%: Week 06 feasibility 2%, Week 07 design review 3%, Weeks 08–11 development evidence 3%, Weeks 13–14 final investigation 5%, and individual defence/handoff 2%; Week 04 and Week 12 are formative.

## AI tutorial content

Show short examples for: Socratic problem interpretation; comparing model levels; algorithm planning; MATLAB code generation with visible units and assumptions; minimal debugging; verification suggestions; and organising verified results into presentation material. Students record only tool/no tool, request, accepted/modified/rejected output, reason, and independent checks—not full chat histories.
