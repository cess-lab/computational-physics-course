# Week 09 Pre-Practical Diagnostic Draft

Use this draft only after the Week 09 materials and questions are approved. Configure one ungraded Google Form quiz through the corresponding Week 09 Google Classroom coursework item; do not create a course-wide routing Form. Collect verified institutional email if identification is required. The six items preserve the standard prediction, units, algorithm/code, diagnosis, validation, and confidence pattern.

| Part | Student prompt | Response format | Answer key and misconception cue |
| --- | --- | --- | --- |
| Physical prediction | A spring is modelled by `F = kx + b`. If `k > 0`, what should happen to force as extension increases? | Multiple choice: increase / remain constant / decrease / cannot tell | **Increase.** Address reading a positive slope as a negative response. |
| Units and scaling | In `F = kx + b`, force is in N and extension is in m. What is the unit of `k`? | Multiple choice: `N` / `m/N` / `N/m` / `N m` | **N/m.** Address attaching the dependent-variable unit to the slope without dividing by the horizontal-axis unit. |
| Algorithm and code | Which order best describes the Core fitting workflow? A. fit -> delete points -> plot -> report; B. plot -> state model -> fit -> residuals -> validate; C. residuals -> fit -> plot -> guess units; D. report -> fit -> validate -> plot. | Multiple choice | **B.** Address fitting before inspecting the data or model. |
| Numerical or defect diagnosis | A residual is defined as `measured - fitted`. If a measured point lies above the fitted line, what sign is its residual? | Multiple choice: positive / zero / negative / sign has no meaning | **Positive.** Address reversing the residual definition. |
| Validation reasoning | In one or two sentences, name one useful independent check for a fitted spring constant and explain what it tests. | Short response | Expected evidence: compare with a supplied nominal/reference spring constant, repeatability range, units, or residual pattern. Do not accept a smooth graph or AI agreement alone. |
| Confidence calibration | How confident are you that you can explain why a high-quality overlay can still hide a poor model? | Linear scale: 1 not yet confident to 5 very confident | No score required. Use responses to decide whether optional remediation should focus on residual patterns and model judgement. |

If the dominant misconception is residual sign or treating visual closeness as sufficient validation, publish one optional 10–15 minute Classroom remediation: show one point above a fitted line, calculate its signed residual, compare random scatter with a U-shaped pattern, reveal the reasoning, and repeat the confidence question. Keep it optional and do not make it a prerequisite for the practical.
