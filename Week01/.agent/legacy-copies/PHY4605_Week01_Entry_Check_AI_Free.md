4. The Forward Euler update is `N_(k+1) = N_k(1 - lambda dt)`. Predict what could happen if `lambda*dt > 1`.
5. Without calculating exact numbers, predict whether reducing `dt` should make the Euler result closer to or farther from the exact solution. State why.
6. Name one piece of evidence you would need before calling a computed decay curve trustworthy.
