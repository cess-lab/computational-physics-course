# Week 11 Learning Note Illustration Decision

No separate ImageGen illustration is required for the Week 11 learning note. The familiar Hooke-law physical model is already a low-representation-barrier context, while the two MATLAB-generated figures directly show the quantitative relationships students must interpret: stiffness-to-extension range and the one-at-a-time comparison of supplied input ranges.

The note therefore uses those retained MATLAB figures as numerical evidence and a deterministic TikZ workflow diagram for the one-at-a-time algorithm. This preserves exact axes, units, values, and output-span relationships without adding a decorative generated image.
