Sensitivity Analysis:
Input Ranges and Output Reliability
Use controlled parameter variation to turn plausible input uncertainty into an output range that can be
validated and interpreted physically.

   Physical question. A spring is loaded by a known force, but its stiffness is only known within a
   plausible range. What range of extension should we report, and what does that range say about
   the reliability of the prediction?



Learning outcomes
1. convert one uncertain input into lower, baseline, and upper one-at-a-time model evaluations;
2. report and validate the resulting output range without false precision; and
3. distinguish parameter uncertainty, numerical approximation error, and model limitation in plain
   language.
How to use this note. Follow the required pathway from model and units to a controlled output
range, an independent validation, and a physical interpretation. Guided extensions contain supplied
relationships to read and interpret; they are not required to complete the pathway.


1. From a parameter sweep to uncertainty evidence
In Week 4, changing a model parameter helped reveal a physical trend. Week 11 uses the same compu-
tational move for a different purpose: the input is not known exactly, so a plausible input range becomes
uncertainty evidence.
The familiar model is the ideal linear spring,

 2. One-at-a-time uncertainty reasoning
 A one-at-a-time sweep changes one uncertain input while keeping the model and every other input fixed.
 In other words, change one input at a time. This lets the resulting output change be attributed to that
 one input range.

                          Choose plausible       Hold model and      Evaluate lower,
                            input range         other inputs fixed   baseline, upper


                             Interpret source     Report output           Validate
                              and limitation         range                baseline


 The computational recipe is:
   1. define the model, baseline, units, and one plausible input range;
   2. hold all other inputs and assumptions fixed;
   3. evaluate the lower, baseline, and upper cases;
   4. collect the minimum and maximum output;
   5. validate one known or hand-calculated case; and
   6. state what the output range means physically.

     Do not vary several uncertain inputs at once when the question asks which input
     caused the change. Simultaneous variation can be useful for other analyses, but it no longer
     isolates one input’s effect.



 3. MATLAB starter code: three controlled cases
 The required calculation needs only a short array and element-wise division. The three stiffness values
 form three controlled evaluations of the same deterministic equation.
          Listing 1: Controlled evaluation of Hooke-law extension cases and their output range.
1 force_baseline_N = 10;
2 stiffness_baseline_Npm = 100;
3 stiffness_cases_Npm = [95 100 105];
4
5 extension_cases_m = force_baseline_N./stiffness_cases_Npm;
6 extension_baseline_m = force_baseline_N/stiffness_baseline_Npm;
7 extension_range_m = [min(extension_cases_m) max(extension_cases_m)];


 The dot in ./ is MATLAB’s element-wise division operator: the scalar force is divided by each array
 value in stiffness_cases_Npm, producing one extension for each stored stiffness. The calculation gives
                                                x0 = 0.10000 m,
 and the range
                                        0.09524 m ≲ x ≲ 0.10526 m.


 4. Report a range, not just a long decimal
 The exact-looking statement “x = 0.10000 m” describes only the baseline case. It hides the fact that the
 stiffness itself is uncertain over the supplied range.

     model predicts an extension of about 0.095 to 0.105 m.

 6. Three different reasons a prediction can be imperfect
 The word “error” is too vague unless its source is identified.

                                                                      105 N m−1
  Numerical                 a mathematical operation is               a finite timestep changes an ODE
  approximation error       approximated numerically                  simulation result

This direct Hooke-law calculation has no timestep, grid, or iterative approximation. Its uncertainty range
comes from the stated stiffness range. Even a perfectly evaluated equation can still inherit uncertainty
from its inputs and limitations from its assumptions.


7. Worked reasoning chain

  Step                          Week 11 evidence
  Physical model                ideal linear spring, x = F/k
  Scale and units               F in N, k in N/m, x in m
  Uncertain input               k = 95, 100, 105 N m−1
  Algorithm                     hold F fixed, evaluate the same model for lower/baseline/upper k
  Output range                  approximately 0.09524 to 0.10526 m
  Validation                    hand-check 10/100 = 0.10 m plus units and trend
  Interpretation                stiffness uncertainty creates a range of plausible model predictions


This chain is more important than memorising a MATLAB function name. In an assessment, syntax may
be supplied; the physical model, held-fixed conditions, uncertainty source, validation, and interpretation
still need to be defended.

Read and interpret the supplied formulas below; deriving or coding them independently is not required.
A normalized sensitivity is a dimensionless measure of how much the output changes fractionally when
one input changes fractionally, near a chosen baseline:

                                                   ∆x/x0

For x = F/k, the supplied local interpretation is approximately Sk = −1 and SF = +1. This is a
local interpretation because it describes small changes near the baseline, not the response over every
possible input value. The sign gives the direction of response; the magnitude describes the fractional
responsiveness near the baseline. Deriving these sensitivities is not required Week 11 work.

This combined estimate answers a different question from the isolated one-at-a-time ranges. The formula
is supplied for interpretation only.
Here uF and uk are standard uncertainties: one-standard-deviation-sized estimates of the uncertainty
in the force and stiffness. Independent means that a deviation in one input is not linked to a deviation
in the other. First-order means that the relation keeps only terms proportional to small changes and
neglects products and higher powers, so it is an approximation for small uncertainties.


Optional extension: beyond one-at-a-time
This extension is optional and not required. Interaction effects are changes produced by combinations
of inputs that cannot be explained by considering each input separately. Global sensitivity compares
influence over the full chosen input ranges or distributions, rather than only near one baseline. Monte
Carlo propagation and correlated-input analysis are further optional methods.


Three takeaways
 1. An uncertain input should be represented by a justified baseline and plausible range before evaluating
    the model.
 2. A one-at-a-time sweep converts that input range into an interpretable output range while keeping
    other inputs fixed.
 3. Parameter uncertainty, numerical approximation error, and model limitation describe different rea-
    sons a prediction may be imperfect.

   Preparation for the practical. Be ready to identify one uncertain input and its units, predict
   the direction of the output change, compute a lower/baseline/upper range using a supplied model,
   perform one independent check, and explain the result without false precision.
