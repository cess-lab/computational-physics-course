| Part | Student prompt | Response format | Answer key and misconception cue |
| --- | --- | --- | --- |
| Physical prediction | For Hooke's law `x = F/k`, force is fixed and stiffness may be slightly higher than the baseline. What should happen to extension? | Multiple choice: increase / decrease / stay identical / become random | **Decrease.** Address reading an uncertainty range as random noise rather than evaluating the same physical model at different plausible inputs. |
| Units and scaling | If `F` is in N and `k` is in N/m, what is the unit of `F/k`? | Multiple choice: N / m / N/m / dimensionless | **m.** Reinforce the unit check before trusting a propagated range. |
| Algorithm and code | Which order best matches one-at-a-time uncertainty analysis? A. vary all inputs -> choose baseline -> report one value; B. define baseline/range -> hold other inputs fixed -> evaluate cases -> report output range; C. plot first -> change model -> guess uncertainty; D. repeat identical input -> call the spread parameter uncertainty. | Multiple choice | **B.** Address simultaneous changes that prevent attribution to one uncertain input. |
| Numerical or defect diagnosis | A student reports `0.100000 m` as the only result even though stiffness is only known from `95` to `105 N/m`. What is the clearest problem? | Multiple choice: MATLAB needs more decimals / false precision hides parameter uncertainty / stiffness should be random / the equation has no units | **False precision hides parameter uncertainty.** |
| Validation reasoning | In one or two sentences, name one independent check for a Hooke-law uncertainty calculation and explain what it tests. | Short response | Expected evidence: hand-check the baseline `10/100 = 0.10 m`; verify units; verify lower `k` gives larger `x`; verify all outputs remain physically plausible for the stated model. Do not accept “the graph is smooth” as the only check. |
| Confidence calibration | How confident are you that you can distinguish parameter uncertainty, numerical approximation error, and model limitation? | Linear scale: 1 not yet confident to 5 very confident | No score required. Use responses to decide whether optional remediation should focus on the three uncertainty-source categories. |

If the dominant misconception is “all uncertainty is numerical error” or “more decimal places make the answer more certain,” publish one optional 10-15 minute Classroom remediation: compare the same exact MATLAB equation using a narrow and wide stiffness range, then contrast that parameter effect with a separate finite-timestep example and one Hooke-law model limitation. End with one retry and the confidence item.
