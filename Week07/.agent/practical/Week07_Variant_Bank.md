# Week 07 Variant Bank

Use only after group submissions are locked. Safe variants include changing one upper integration limit, changing one interval count while keeping the model fixed, changing the initial force/current, changing the decay time, changing the force length scale, omitting the independent-variable coordinates from `trapz`, reversing the integration-coordinate order, using the wrong upper limit, or asking the student to identify whether a stated integral unit is physically consistent.

Keep the defence focused on physical accumulation, explicit integration limits, trapezoidal geometry, sample spacing, `trapz(x,y)`, refinement, analytic/reference validation, simple error, units, and physical meaning. Do not require quadrature error-order derivations, independent multi-rule implementation, or adaptive quadrature as Core defence evidence.
