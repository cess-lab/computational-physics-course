# Week 02 Instructor Support Bundle

This hidden backend bundle supports `Week02/Week02_Practical_AI_Enabled_Loops_and_Debugging_Challenge_Set.m`. The student-facing challenge remains the wording authority. The bundle adds staff guidance, reference evidence, assessment and defence records, and local QA; it does not create or publish a Form, Classroom item, or other external record.

## Operating rules

- Use the ten questions in the student challenge as the progressive sequence: cooling (1–6), radioactive decay (7–8), and mass-spring oscillation (9), followed by cross-context comparison and AI declaration (10).
- Keep the supplied equations, assumptions, variables, units, and MATLAB release requirement unchanged unless a post-submission variant explicitly changes one parameter or one clear defect.
- Students may use generative AI, but code volume is not the criterion. Require model/units, algorithm or pseudocode, traceable output, validation, physical interpretation, and a concise decision record.
- Require all ten group questions. For the course portfolio, apply the assessment blueprint's best-eight rule across the ten weekly packets; this bundle scores the Week02 packet itself.
- Draw the question slot, variant, and student only after the group submission is locked. Do not select the same group member again until every member has one completed defence. Record an absence as pending until its make-up defence is completed.
